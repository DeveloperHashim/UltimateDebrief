# UltimateDebrief
The first-ever Hitman 3 mod that puts YOU in control of the rating screen.

Tired of seeing the same background every time you finish a contract? Ultimate Debrief Mod replaces the default rating and debrief screens with high-quality, customized variants featuring Agent 47 in iconic suits and poses. 

*   **Game Mode Support:** Fully supports Story Mode and Freelancer.
*   **Total Control:** Unlike other background replacers that force one style on you, this mod puts you in control with multiple selectable options.

## ⚙️ Requirements
To use this mod, you need:
*   [Simple Mod Framework (SMF)](https://www.nexusmods.com/hitman3/mods/200)

## 🛠️ Installation Instructions
This mod strictly requires the **Simple Mod Framework** to function and allow option selection.

1.  Download the Latest version through Releases.
2.  Open the Simple Mod Framework (Mod Manager) and import the downloaded `.zip` file through **Add a Mod**.
3.  Enable the mod in order to see the gear icon next to it.
4.  Click on the **Gear Icon** and select your preferred option for Story Mode and the various Freelancer stages.
5.  Click **Deploy** and enjoy!

> **Important Note:** Whenever you change an option in the Mod Manager, make sure to redeploy the mod to see the changes applied in-game!
